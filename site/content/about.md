안녕하세요. 전북대학교 **바이오메디컬공학부 3학년 채다연**입니다.
생명 현상을 데이터로 기록하고 비교하는 **생명정보학**에 관심을 두고 공부하고 있습니다.

## 관심 분야: 생명정보학 {#interest}

고등학생 때 생명정보학 기초 실습을 해 본 적이 있습니다.
그때 생명에 관한 정보를 **데이터로 기록하고 서로 비교할 수 있다**는 점이 매력적으로 느껴졌습니다.
이 경험을 계기로 생명과학과 공학을 함께 배울 수 있는 바이오메디컬공학부에 진학했습니다.

## 학습 목표와 실행 계획 {#goal}

**목표:** 생물 서열 데이터를 Python으로 직접 읽고 분석할 수 있게 되는 것

생명정보학은 결국 데이터를 다루는 일이어서, 남이 만든 결과를 보는 데서 그치지 않고 직접 데이터를 열어 보고 싶습니다.

**다음 행동:**

1. 2026년 겨울방학 동안 [Biopython 공식 튜토리얼](https://biopython.org/DIST/docs/tutorial/Tutorial.html)의 서열 파일 읽기 부분을 따라 해 본다.
2. FASTA 파일을 읽어 서열 길이와 GC 함량을 계산하는 짧은 스크립트를 만든다.
3. 만든 스크립트와 실행 결과를 GitHub 저장소에 올리고, 이 사이트의 활동 목록에 기록한다.
