## 목적 {#purpose}

1학년 웹페이지는 링크가 만료되면서 결과물이 사라졌습니다.
이번에는 **소스와 수정 이력이 저장소에 남고, push만 하면 공개 사이트가 다시 만들어지는 구조**로 포트폴리오를 만드는 것이 목표입니다.

## 수행 과정 {#process}

1. **테마 선택과 배포 준비:** Hugo Themes에서 Terminal 테마를 골라 ZIP으로 받고, 수업에서 제공한 스크립트로 GitHub Actions 배포 파일을 만들었습니다.
2. **설정 바꾸기:** 사이트 언어를 한국어(`lang="ko"`)로, 주소를 내 GitHub Pages 주소로, 메뉴를 홈·소개·대표 활동·GitHub으로 바꿨습니다.
3. **예시 내용 지우고 내 글 쓰기:** 테마 예시 글(가짜 작성자, 피규어 사진)을 지우고 소개와 활동 글을 작성했습니다.
4. **점검하고 고치기:** 1440px·768px·390px 화면과 키보드 Tab 이동을 확인하며 문제를 찾아 고쳤습니다.

**Hugo를 고른 이유:** 글을 Markdown 파일로만 써도 사이트가 만들어지고, 결과가 HTML 파일이라 GitHub Pages에 무료로 올릴 수 있기 때문입니다.
테마 파일을 직접 고치는 대신 `site/layouts/`와 `site/static/style.css`에서 덮어쓰는 방식을 택해, 원본 테마와 내가 바꾼 부분을 구분할 수 있게 했습니다.

## 결과와 확인한 것 {#result}

| 확인한 문제 | 원인 | 고친 방법 |
| --- | --- | --- |
| 390px 화면에서 메뉴가 `Menu ▾` 안에 숨고, Tab으로 열 수 없음 | 테마의 메뉴 열기 버튼이 `<li>`라 키보드 초점을 받지 못함 | 메뉴 4개를 모든 화면에서 항상 보이게 바꿈 |
| "생명정보학"이 "생명정/보학"처럼 단어 중간에서 줄바꿈 | 테마가 모든 요소(`*`)에 `word-break: break-word` 지정 | 같은 선택자로 `word-break: keep-all` 덮어씀 (처음에 `body`에만 넣었다가 적용되지 않아 다시 고침) |
| 외부 글꼴 요청 실패 | 색상 CSS에 외부 CDN 글꼴 `@import`가 남아 있었음 | 저장소에 이미 있는 Fira Code만 쓰도록 `@import` 제거 |

## 배운 점과 다음 계획 {#lessons}

- 화면이 잘 보이는 것과 **키보드나 좁은 화면에서도 쓸 수 있는 것**은 다르다는 점을 직접 확인했습니다.
- CSS가 적용되지 않을 때 내가 쓴 규칙만 볼 게 아니라, **원래 어떤 규칙이 더 구체적으로 걸려 있는지** 찾아야 한다는 것을 배웠습니다.
