## 활동 개요 {#overview}

| 항목 | 내용 |
| --- | --- |
| 수행 시기 | 2024년 1학기 (1학년) |
| 수업 | 웹프로그래밍 기초 |
| 진행 상태 | **완료** (과제 제출 완료, 당시 공개 링크는 현재 만료됨) |
| 수행 형태 | **개인 수행**: 기획, 페이지 구성, HTML·CSS 작성을 모두 혼자 진행 |
| 사용 기술 | HTML, CSS, JavaScript(수업에서 제공한 코드 적용) |

## 목적 {#purpose}

수업에서 배운 HTML과 CSS를 실제로 써서 **나를 소개하는 여러 페이지짜리 웹사이트를 처음부터 끝까지 만들어 보는 것**이 과제의 목표였습니다.
한 페이지짜리 연습이 아니라 메뉴로 여러 페이지를 오가는 구조를 직접 만들어 보는 데 의미를 두었습니다.

## 수행 과정 {#process}

1. **메뉴 구성 정하기:** 나를 소개할 내용을 MAIN, STORY, ALBUM, MAJOR, POSTER, RESUME, BUCKIT-LIST, JBNU의 8개 메뉴로 나눴습니다.
2. **첫 화면 만들기:** 각 메뉴로 들어갈 수 있는 랜딩 페이지를 만들고, 메뉴마다 어떤 내용이 있는지 한 줄 설명을 붙였습니다.
3. **페이지별 레이아웃 작성:** 메인 화면은 표(table)로 칸을 나눠 프로필, 소개, 좋아하는 것을 배치했고, 버킷리스트와 전공 페이지는 카드 형태의 박스로 꾸몄습니다.
4. **배경 효과 적용:** 첫 화면의 풀스크린 배경 슬라이드는 수업에서 제공한 JavaScript 코드(VEGAS2)를 안내받은 사용법대로 붙여 넣어 적용했습니다.

**도구를 고른 이유:** 과제의 목적이 수업에서 배운 HTML과 CSS를 직접 써 보는 것이었기 때문에, 화면 구조와 꾸미기는 다른 프레임워크 없이 HTML·CSS로만 작성했습니다.
JavaScript는 아직 배우기 전이라 직접 작성하지 않고, 수업에서 제공된 코드를 그대로 활용하는 쪽을 선택했습니다.
